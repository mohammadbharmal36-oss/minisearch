HTTP Protocol Basics

Requests and responses

The crawler speaks plain HTTP. It issues GET requests with a User-Agent header, honors redirects up to a small cap, records the final response code, and enforces connect and total timeouts so a silent server can never stall a crawl job indefinitely.

Status codes

A 200 response with an HTML content type is indexed. Client errors such as 404 and 410 are recorded as failures and never retried within the same job. Server errors are also recorded; a future scheduler could re-try them later with backoff. Redirect chains are followed, and the final URL is what gets indexed.
