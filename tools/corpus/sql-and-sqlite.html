SQL and SQLite

Why SQL here

A search engine needs durable, queryable metadata: which URL was crawled when, with what title and description. SQLite provides a complete SQL database in a single file with no server, which suits a self-contained engine perfectly.

Schema of MiniSearch

MiniSearch stores one documents table with the URL as a unique key, plus text columns for the title, description, extracted content, headings and outgoing links. The inverted index itself lives in a compact serialized binary file that loads in milliseconds; SQLite is the source of truth the index is rebuilt from when needed.
