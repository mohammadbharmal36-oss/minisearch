The Standard Template Library

Containers for search

The STL provides exactly the containers an inverted index needs: unordered_map for term lookup, vector for posting lists, and sort plus lower_bound for keeping lists ordered by document id. Reserving capacity and keeping postings contiguous keeps the index cache friendly.

Algorithms

Standard algorithms such as sort, stable_sort, set operations and binary search implement most of the index's mechanics in a few lines each, which is why the hand-written core stays readable and auditable.
