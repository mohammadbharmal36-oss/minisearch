C++ Programming Language

Overview

C++ is a general-purpose programming language created by Bjarne Stroustrup. It compiles to native code, gives the programmer direct control over memory and hardware, and pairs that control with zero-overhead abstractions such as templates, move semantics and the standard template library.

MiniSearch itself is written in modern C++17: the inverted index, the ranking functions, the query parser and the crawler are all C++ code built with CMake.

Memory and the STL

Smart pointers make ownership explicit; RAII ties resource lifetimes to scopes; and the standard template library provides the hash maps, vectors and algorithms the index is built on. A search engine is a memory-bound program, so cache-friendly contiguous posting lists matter more than clever pointer structures.

Competitive programming

C++ is used in competitive programming because the standard template library ships battle-tested data structures and the language rewards precise control of complexity. The classic phrase competitive programming appears verbatim in this corpus for phrase search demonstrations.
