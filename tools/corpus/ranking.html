Ranking Functions Compared

Same candidates, different orders

TF-IDF and BM25 receive exactly the same candidate documents from the query processor; they only differ in how they score. On simple queries their rankings often agree at the top and drift lower down. On queries with repeated terms or on collections with mixed document lengths, BM25 tends to prefer focused, medium-sized documents while TF-IDF favors repetition and short documents.

Choosing in MiniSearch

The search interface and the API both accept an algorithm parameter with the values tfidf and bm25, so the same query can be run through both functions and the results compared directly. The analytics page reports the average search latency across whichever function was used.

Both implementations are hand-written C++ over the same posting lists; no third-party ranking library is involved anywhere in the engine.
