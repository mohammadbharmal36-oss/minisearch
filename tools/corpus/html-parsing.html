HTML Parsing

What to keep

A search engine does not index markup. The parser walks the HTML tree and extracts the title, meta description, canonical URL, heading text for h1 and h2, hyperlink targets, and the visible body text. Scripts, styles, templates, navigation, asides and footers are skipped because they are chrome, not content.

Why a real parser

Stripping tags with regular expressions fails on nested quotes, comments containing tag-like text, and malformed markup. A conformant HTML5 parser recovers from errors the same way browsers do. MiniSearch uses Gumbo, Google's HTML5 parsing library, for exactly this reason; the extraction rules, however, are its own.
