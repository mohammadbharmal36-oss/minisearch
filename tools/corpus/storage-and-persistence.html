Persistence

What persists

MiniSearch persists two things: the SQLite database with every document's metadata and content, and a binary serialization of the inverted index with delta-encoded posting lists. Saving is atomic - a temporary file is fully written and then renamed - so a crash mid-save can never destroy a good index.

Startup

On startup the engine loads the index file and reconciles it with the database: new documents are indexed incrementally, postings of deleted documents are dropped, and a corrupted index file is detected by its header and structural checks and rebuilt honestly rather than trusted.
