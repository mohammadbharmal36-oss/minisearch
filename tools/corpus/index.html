Programming and Search Documentation

Overview

This small website is a corpus of self-written documentation pages about search engines, information retrieval, and several programming languages. The MiniSearch crawler explores it over plain HTTP, parses the HTML, tokenizes the text and builds an inverted index.

Every page is plain semantic HTML with a title, a meta description, headings, paragraphs and hyperlinks to related pages. There is nothing hidden behind JavaScript: what the crawler downloads is what the parser sees.

How to read this corpus

Follow the See also links to travel the graph the way the crawler does. The pages about the inverted index, TF-IDF and BM25 describe the algorithms this engine implements in C++. The pages about crawling and robots.txt describe the polite fetching behavior you can observe in the crawler console.

One page is deliberately hidden: the robots.txt file disallows the private directory, and the crawler must respect that.

A note on privacy

There is also a private page that robots.txt forbids crawling. It contains the word zanzibar and nothing else of value. If you can search for zanzibar and find it, something is wrong with the crawler's manners.
