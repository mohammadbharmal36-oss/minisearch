Glossary

Terms

Crawler: the program that downloads pages. Frontier: the queue of URLs awaiting fetch. Posting: one term's occurrence record in one document, with frequencies and positions. Posting list: the sorted list of postings for one term. Token: one normalized word. Term: the canonical index key a token maps to.

TF-IDF: term frequency times inverse document frequency. BM25: the saturated, length-normalized ranking function. Inverted index: the term-to-documents mapping. Snippet: the short excerpt shown under a search result. robots.txt: the site-level crawl permission file.
