Query Processing

Parsing

A query is parsed by a small recursive descent parser. Operators are AND, OR and NOT, quoted phrases match exact word order, and parentheses group expressions. Adjacent terms imply AND, so the query python programming behaves like python AND programming.

The parser normalizes terms with the same tokenizer the indexer uses, including the technical term mapping that preserves expressions like C++ and Node.js as single searchable terms.

Evaluation

Evaluation walks the parse tree and combines posting lists with two-pointer set operations over sorted document ids. A phrase node verifies adjacent positions using the stored word positions. NOT subtracts the operand's documents from the positive side instead of scoring it.
