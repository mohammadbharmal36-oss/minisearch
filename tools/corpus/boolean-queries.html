Boolean Queries

Semantics

The query cpp AND programming returns documents containing both terms. The query cpp OR python returns documents containing either term. The query programming NOT python returns documents about programming that do not mention python. Parentheses make combinations explicit, and operator words are recognized case-insensitively.

Efficiency

Because posting lists are sorted by document id, intersection and union run in time linear in the combined list sizes with two cursors, never with nested loops or hash rehashing. Subtraction for NOT works the same way.
