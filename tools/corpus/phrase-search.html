Phrase Search

How it works

A quoted query such as "competitive programming" asks for documents where the two words appear next to each other, in that order. The engine takes the posting lists of both terms, intersects the document sets, and then checks the stored positions: the phrase matches a document if some position p holds the first term and position p plus one holds the second.

Stop words are kept inside phrases, so "state of the art" matches the actual four-word sequence rather than three unrelated words.

Field boundaries

MiniSearch inserts gaps between fields in its virtual position stream. A document titled Python Guide whose body starts with the word python does not match the phrase guide python, because the last title position and the first body position are deliberately not adjacent.
