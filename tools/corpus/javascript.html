JavaScript and Node.js

In the browser

JavaScript is the programming language of the web platform. This corpus is deliberately static HTML with no scripts, because a crawler that indexes what a server returns should not depend on executing client-side code. The MiniSearch web interface, however, is vanilla JavaScript fetching JSON from the search API.

On the server with Node.js

Node.js brought the language to the server with an event loop and a vast package registry. Writing a search engine in C++ while its web front-end is a few kilobytes of JavaScript is a deliberate contrast: the heavy lifting stays native, the interface stays simple.
