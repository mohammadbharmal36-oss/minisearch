About this engine

Independently built

The crawler, inverted index, TF-IDF and BM25 ranking, and the Boolean & phrase query engine are all written from scratch in C++17. No external search library does the work.

Real results only

Every result was genuinely crawled over HTTP, parsed, tokenized, indexed and ranked by this engine. Nothing on this site is hardcoded.

Open operations
